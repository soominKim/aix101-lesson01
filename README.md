# AIX101 · L01 실습 가이드 — 나만의 ML 모델 만들고 웹서비스로 배포하기

Teachable Machine → Google AI Studio → Netlify 로 이어지는 실습을
캡쳐 화면 그대로 따라할 수 있는 **원페이지 가이드**입니다.

🔗 **가이드 페이지:** https://soominkim.github.io/aix101-lesson01/

## 구성
- **나만의 프롬프트 만들기** (페이지 상단): 본인의 Teachable Machine 모델 URL과 직접 만든 분류(카테고리)를 입력하면 프롬프트가 자동 완성 → 복사해서 Google AI Studio에 붙여넣기
- **STEP 01. Teachable Machine** — 웹캠으로 이미지 분류 ML 모델 만들기
- **STEP 02. Google AI Studio** — 프롬프트로 웹 서비스 만들기
- **STEP 03. Netlify** — 완성한 앱 배포하기
- **실습 PDF 다운로드**

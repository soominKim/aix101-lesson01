나만의 프롬프트 만들기

본인의 Teachable Machine 모델 URL과 직접 만든 분류(카테고리)를 입력하면 프롬프트가 자동으로 완성됩니다. 완성된 프롬프트를 복사해서 Google AI Studio에 그대로 붙여넣으세요.

내 모델 정보 입력

입력하는 즉시 오른쪽 프롬프트가 업데이트됩니다.

분류(카테고리) 이름 · 의미 · 멘트
완성된 프롬프트

      1Teachable Machine · ML 모델 만들기
      
웹캠으로 이미지 분류 모델 학습하기

      
구글에서 만든 웹 기반 노코드 인공지능 학습 툴입니다. 코딩 없이 이미지·사운드·자세를 인식하는 모델을 만들 수 있어요.
        teachablemachine.withgoogle.com ↗
      

    


    

      

        
        

          STEP 1 · 2
          
사이트 접속 후 Get Started

          
teachablemachine.withgoogle.com에 접속하고 Get Started 버튼을 누릅니다.

        

      

      

        
        

          STEP 3
          
이미지 프로젝트 선택

          
새 프로젝트에서 이미지 프로젝트를 선택합니다.

        

      

      

        
        

          STEP 4
          
표준 이미지 모델 선택

          
대부분의 용도에 적합한 표준 이미지 모델을 선택합니다.

        

      

      

        
        

          STEP 5 · 6
          
첫 번째 클래스 이름 지정 → 웹캠 선택

          
첫 번째 클래스의 이름을 정하고(예: Soomin), 웹캠을 선택합니다.

        

      

      

        
        

          STEP 7
          
녹화 버튼을 길게 눌러 샘플링

          
웹캠 녹화 버튼을 길게 눌러 이미지를 수집합니다. (이미지 직접 업로드도 가능)

        

      

      

        
        

          STEP 8 · 9
          
두 번째 클래스 & 클래스 추가

          
두 번째 클래스 이름을 정하고 동일하게 샘플링합니다. 클래스 추가로 세 번째, 네 번째… 계속 추가할 수 있어요.

        

      

      

        
        

          STEP 10
          
모델 학습시키기

          
클래스별 데이터 입력이 끝나면 모델 학습시키기 버튼을 누릅니다. (학습 중 탭을 전환하지 마세요.)

        

      

      

        
        

          STEP 11
          
미리보기로 동작 확인

          
오른쪽 미리보기에서 모델이 잘 작동하는지 확인합니다. 정확하지 않으면 앞 단계를 수정해보세요.

        

      

      

        
        

          STEP 12
          
모델 내보내기

          
미리보기 상단의 모델 내보내기 버튼을 누릅니다.

        

      

      

        
        

          STEP 13
          
모델 업로드 (Tensorflow.js)

          
Tensorflow.js 탭 → 업로드(공유 가능한 링크) → 모델 업로드 버튼을 누릅니다.

        

      

      

        
        

          참고
          
무엇이 게시되나요?

          
학습 결과물인 모델 파일(가중치 등)만 Google 서버에 게시됩니다. 내가 사용한 예시 이미지는 게시되지 않아요.

        

      


      

        !
        

          
STEP 14 — 공유 가능한 링크(URL)를 꼭 메모장에 저장하세요!

          
이 https://teachablemachine.withgoogle.com/models/… URL을 위쪽 프롬프트 만들기의 모델 URL 칸에 붙여넣습니다. 이 링크가 다음 단계의 핵심입니다.

        

      


      

        
        

          STEP 14
          
모델 URL 복사 & 저장

          
공유 가능한 링크 옆의 복사 버튼을 눌러 URL을 메모장에 저장해 두세요.

        

      

      

        
        

          배경지식
          
model.json 은?

          
추출된 이미지 특징을 내부 층으로 변환하고(ReLU), 최종적으로 클래스 점수를 Softmax로 확률화하는 모델의 구조가 담깁니다.

        

      

      

        
        

          배경지식
          
weights.bin 은?

          
학습을 통해 만들어진 실제 가중치(숫자) 값이 담긴 파일입니다. 모델이 판단을 내리는 실질적인 근거예요.

        

      

    

  










  

    

      2Google AI Studio · 웹 서비스 만들기
      
프롬프트로 웹 앱 생성하기

      
제미나이를 활용해 생성형 AI를 실험하고, 프롬프트를 설계하고, 결과를 바로 확인할 수 있는 웹 기반 개발 환경입니다.
        aistudio.google.com/apps ↗
      

    


    

      

        
        

          STEP 1
          
New app 선택

          
AI Studio 왼쪽 메뉴에서 New app을 선택합니다.

        

      

      

        
        

          STEP 2
          
프롬프트 붙여넣기 → Build

          
위에서 만든 나만의 프롬프트를 입력창에 붙여넣고 Build 버튼을 누릅니다.

        

      

      

        
        

          프롬프트 미리보기
          
어떤 프롬프트를 넣나요? (1)

          
모델 URL, 카테고리, 각 카테고리의 의미와 위트 있는 멘트를 지정합니다. 위 프롬프트 만들기에서 자동 생성돼요.

        

      

      

        
        

          프롬프트 미리보기
          
어떤 프롬프트를 넣나요? (2)

          
Capture 카드 저장, 모바일 대응, 그리고 실제 모델 예측만 사용하도록 하는 중요/에러 방지 지침까지 포함됩니다.

        

      

      

        
        

          STEP 3
          
디자인 선택

          
생성 중 디자인 제안이 뜨면 마음에 드는 스타일을 고르고 Select this design을 누릅니다.

        

      

      

        
        

          STEP 4
          
에러가 나면 Fix

          
하단에 오류가 표시되면 Fix 버튼을 눌러 자동으로 수정합니다. 미리보기가 정상 동작할 때까지 반복하세요.

        

      

      

        
        

          STEP 5
          
코드 다운로드 (zip)

          
상단 Code 탭 → Export → Download as .zip으로 코드를 내려받고 압축을 풉니다.

        

      

      

        
        

          참고
          
labs.google · Google Flow

          
더 다양한 생성형 AI 실험이 궁금하다면 labs.google도 둘러보세요.

        

      

    

  










  

    

      3Netlify · 배포하기
      
완성한 앱을 웹에 배포하기

      
웹 프로젝트의 빌드·배포·운영을 자동화하는 웹 개발 플랫폼입니다. 다운로드한 폴더를 드래그 앤 드롭만 하면 배포 끝.
        netlify.com ↗
      

    


    

      

        
        

          STEP 1
          
Projects → 폴더 드래그 앤 드롭

          
Projects 메뉴를 클릭한 뒤, AI Studio에서 다운로드해 압축 푼 폴더를 배포 영역에 드래그 앤 드롭합니다.

        

      

      

        
        

          STEP 2
          
업로드 완료

          
파일이 업로드되고 배포(deploy)가 완료되면 Published deploy 메시지가 표시됩니다.

        

      

      

        
        

          STEP 3
          
Project Overview → 링크 접속

          
Project overview에서 초록색 사이트 링크를 클릭해 접속합니다. (카메라 권한은 허용)

        

      

      

        
        

          STEP 4
          
Make public & URL 지정

          
Make public으로 누구나 접속 가능하게 만들고, 원하는 사이트 URL(예: my-face-vibe)을 입력해 완성합니다.

        

      

    

  










  

    

      
🎉 완성

      
최종 결과물

      
웹캠으로 실시간 분류하고, 위트 있는 멘트와 함께 Capture 카드로 저장되는 나만의 웹 서비스가 완성됩니다.
